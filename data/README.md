# Data sources

Files are stored in data/ and can be used without downloading them again.

- nzge.rds: nzge from the archived CRAN nzelect package, downloaded from https://raw.githubusercontent.com/cran/nzelect/master/data/nzge.rda and saved as RDS without changing its contents. Contains 728,602 rows and 9 columns for 2002, 2005, 2008, 2011, and 2014. The pasted assignment omitted the actual link behind “here”, so this is the package dataset, not a verified copy of the instructor-hosted RDS.
- atp_matches_2019.csv: https://raw.githubusercontent.com/azhou5849/tennis-atp-sackmann-data/master/atp_matches_2019.csv
- us-states.csv: https://raw.githubusercontent.com/nytimes/covid-19-data/refs/heads/master/rolling-averages/us-states.csv . Includes cases_avg_per_100k, so population-standardized daily averages are already available.

The CSV files were saved as downloaded; no filtering or analysis was performed.

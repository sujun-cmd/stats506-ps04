# STATS 506 — Homework 4

Author: Jun Su

R analyses of New Zealand elections, 2019 ATP tennis matches, and COVID-19 trends.

## Files

- `ps04.qmd`: Quarto source code and answers.
- `ps04.html`: Rendered report; open in a web browser.
- `data/`: Datasets and source information.

## Run

With R, Quarto, and the required R packages installed, run from the repository folder:

```bash
quarto render ps04.qmd
```
